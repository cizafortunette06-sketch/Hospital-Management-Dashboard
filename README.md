# Hospital Management Dashboard

## Project Overview
This project presents an interactive Hospital Management Dashboard developed using Microsoft Power BI. The dashboard provides an overview of hospital operations and allows users to explore patient, appointment, doctor, treatment, and billing data.

## Project Objectives
- Monitor key hospital performance indicators.
- Analyze patient and appointment information.
- Explore doctors' specializations and experience.
- Track treatment records.
- Analyze billing amounts and payment statuses.
- Support data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI – Data visualization and dashboard development.
- Microsoft Excel – Dataset preparation and data source.
- DAX – Measures and KPI calculations.

## Dashboard Features

### 1. Executive Overview
The first page provides a high-level summary of hospital operations.

**Key Performance Indicators (KPIs):**
- Total Patients
- Total Appointments
- Total Doctors
- Total Treatments
- Total Revenue

**Visualizations:**
- Appointments by Status
- Patients by Gender
- Doctors by Experience
- Amount by Payment Status
- Doctors by Specialization
- Treatment Count
- Appointment Count
- Average Amount by Payment Status

### 2. Detailed Analysis
The second page provides detailed information through five tables:
- Patients
- Appointments
- Doctors
- Billing
- Treatments

**Interactive Filters (Slicers):**
- Appointment Status
- Patient Gender
- Doctor Specialization

## Data Analysis
The dashboard allows users to explore hospital data, compare operational indicators, and filter information interactively.
